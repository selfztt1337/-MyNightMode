# NightMode 1.1.2 — Release Notes

Версия 1.1.2 исправляет отображение иконки в README, Dock, Finder и внутри NightMode. Приложение снова следует системной светлой или тёмной теме.

## Главное

- светлая иконка используется для GitHub README, Finder и Dock;
- внутри приложения иконка переключается по системной теме macOS;
- прозрачность macOS-иконок сохранена;
- независимые профили для каждого подключённого дисплея;
- расписание по времени или от заката до рассвета;
- пользовательские пресеты с иконкой, предпросмотром, редактированием и JSON-импортом;
- AI Auto с адаптацией к активному приложению, яркости и времени суток;
- регулируемые Paper Mode и Focus Edges;
- диагностика полного покрытия внешних мониторов;
- компактное управление из menu bar;
- назначаемая глобальная горячая клавиша;
- системные светлая и тёмная темы с согласованной иконкой приложения;
- улучшенные VoiceOver-подписи, клавиатурная навигация и Reduce Motion.
- безопасный импорт пользовательских пресетов с ограничением размера файла;
- обезличенный экспорт диагностического отчёта.

## Установка

1. Скачайте `NightMode-1.1.2.dmg` из GitHub Releases.
2. Откройте образ и перенесите `NightMode.app` в папку «Программы».
3. Запустите приложение. Если macOS покажет предупреждение для локально подписанной сборки, откройте **Системные настройки → Конфиденциальность и безопасность** и подтвердите запуск.
4. Выберите дисплей, включите защиту и настройте силу эффекта. Разрешения Screen Recording и Accessibility не требуются.

## Обновление с 1.0.0

Замените прежний `NightMode.app` в папке «Программы». Существующие настройки мигрируют автоматически; параметры новых функций получают безопасные значения по умолчанию.

## Известные ограничения

- аппаратная яркость внешнего монитора доступна только тогда, когда macOS публикует её через IOKit;
- приложение локально подписывается при самостоятельной сборке; публичный релиз желательно подписать Developer ID и нотариализовать.

## Проверено

- core behavior checks;
- рендер основных экранов в светлой и тёмной темах;
- полный release build и проверка подписи;
- наличие ресурсов внутри `.app`;
- повторный запуск без создания второй копии;
- аудит секретов, локальных путей и внешних зависимостей.
