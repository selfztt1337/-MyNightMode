# Тестирование NightMode

## Автоматический прогон

```bash
./scripts/test_core_logic.sh
./scripts/test_views.sh
./scripts/benchmark_core_logic.sh
./scripts/audit_repository.sh
./scripts/build_app.sh
```

Последняя команда создаёт release-сборку, проверяет подпись и запускает приложение.

## Автоматически проверяется

- Overlay создаётся как `.nonactivatingPanel`.
- `canBecomeKey` и `canBecomeMain` всегда возвращают `false`.
- `ignoresMouseEvents = true`.
- Overlay не передаётся в системный шаринг: `sharingType = .none`.
- Эффект не использует ScreenCaptureKit, Screen Recording или Accessibility.
- Изменения режима и интенсивности применяются без перезапуска.
- Интенсивность выбранного дисплея можно настроить до включения эффекта.
- Расписание корректно выбирает событие до утра, днём и после вечернего перехода.
- Ручной override заканчивается на ближайшем переходе расписания.
- Старые профили дисплеев декодируются с безопасными значениями Focus Edges, теплоты и Paper Mode.
- Пользовательские пресеты проходят JSON round-trip и миграцию старого формата.
- Неизвестные приложения получают безопасный рабочий AI-профиль, а известные категории macOS классифицируются без закрытого списка bundle ID.
- AI-режим блокирует применение ручных пресетов во всех поверхностях управления.
- Создание шестого пользовательского пресета отклоняется; существующие пять можно редактировать.
- Предпросмотр пресета проходит отдельную smoke-проверку минимального размера.
- Live Preview проверяется в двух состояниях: защита была выключена и защита уже работала.
- При выключенной защите Live Preview показывает overlay только на выбранном дисплее и корректно отменяет предыдущий таймер.
- Повторное назначение пользовательского пресета в занятый слот отдаёт слот последнему действию.
- Выходящие за диапазон числа из JSON и сохранённого профиля нормализуются до безопасных значений.
- Статус профиля соответствует выбранному дисплею, а не всегда главному экрану.
- Замена встроенного слота и добавление пресетов в прокручиваемую ленту имеют детерминированный порядок.
- Menu bar проходит smoke-проверку минимального размера и не схлопывается в полосу.
- Для каждого `NSScreen` создаётся независимая панель полного размера.
- Одинаковое состояние не создаёт повторную Core Animation транзакцию.
- Скрипты сборки проходят shell syntax check.
- Info.plist проходит `plutil` на macOS через build script.
- Tracked-файлы проходят автоматический аудит приватности и секретов.
- Главное окно, настройки, onboarding и preview рендерятся в светлой и тёмной темах.
- Экспорт диагностики не содержит локальных путей, имени пользователя и пользовательских имён дисплеев.
- Preview с некорректной длительностью безопасно игнорируется.

## Ручная release-регрессия

- клики, скролл, drag-and-drop и ввод текста под overlay;
- глобальный пользовательский хоткей;
- выбор режимов, встроенных и пользовательских пресетов в главном окне и menu bar;
- Smart Pause и автоматическое возобновление;
- Paper Mode и Focus Edges;
- несколько мониторов;
- Mission Control и полноэкранный режим;
- субъективная комфортность режимов.
