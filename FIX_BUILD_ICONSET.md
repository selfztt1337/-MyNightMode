# Исправление сборки iconset

Исправлена ошибка `parameter not set` на шаге `[3/6] Resources`.

Причина: zsh с `set -u` не разбивал строку параметров через `set -- $spec`, поэтому переменная `$2` отсутствовала.

Исправление: размеры и имена иконок теперь читаются построчно через `read`, без неявного word splitting.
