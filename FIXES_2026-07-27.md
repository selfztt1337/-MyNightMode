# Исправления сборки

Исправлены ошибки компиляции из лога пользователя:

- передача `CGRect.size` в конфигурацию ScreenCaptureKit;
- явный `SCStreamOutputType.screen`;
- безопасная обработка `kCGWindowBounds`;
- `settings` сделан изменяемым для SwiftUI bindings.

Предупреждения Core Image о deprecated API не блокируют сборку.
