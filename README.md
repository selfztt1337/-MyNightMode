# MyNightMode

Минималистичный полноэкранный eye-comfort фильтр для macOS.

## Что умеет

- Полностью затемняет все подключённые экраны без обрезки по координатам.
- Не перехватывает мышь, клавиатуру, скролл и drag-and-drop.
- Не требует Screen Recording или Accessibility.
- AI-режим определяет тип активного приложения: работа, чтение, игры или обычный режим.
- AI-режим учитывает текущую аппаратную яркость дисплея, когда macOS отдаёт её через IOKit.
- Ручные режимы: Работа, Чтение, Игры.
- Управление из menu bar и горячей клавишей ⌥⌘D.
- Вся работа локальная.

created by @selfztt1337

## Сборка в VS Code

1. Установить Apple Command Line Tools: `xcode-select --install`.
2. Открыть папку проекта в VS Code.
3. Нажать `⌘⇧B` и выбрать `1. Build MyNightMode.app`.
4. Запустить задачу `2. Run MyNightMode`.
5. DMG создаётся задачей `3. Create MyNightMode.dmg`.

## Честные ограничения

- macOS не разрешает приложению менять цвета или CSS внутри Miro и других чужих приложений. MyNightMode использует click-through полноэкранный фильтр.
- Чтение аппаратной яркости зависит от модели Mac и дисплея. При недоступности значения AI использует безопасное значение по умолчанию.
- Проект статически проверен в текущей среде, но финальная компиляция AppKit/IOKit и визуальная QA-проверка выполняются на macOS.
