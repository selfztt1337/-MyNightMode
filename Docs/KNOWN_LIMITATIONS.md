# Известные ограничения

1. macOS не предоставляет публичного API для настоящего CSS-подобного dark mode поверх произвольного чужого приложения.
2. Интерактивный режим использует прозрачный цветовой слой, поэтому белый фон становится тёмно-серым, а не полностью перестраивается как нативная тема.
3. Overlay находится поверх всего экрана и не перехватывает события. Некоторые системные элементы, находящиеся выше floating-level, могут отображаться поверх него.
4. Названия окон во всех Spaces зависят от разрешения Screen Recording и поведения конкретного приложения.
5. Реальная проверка нескольких мониторов и полноэкранного Miro возможна только на macOS.
