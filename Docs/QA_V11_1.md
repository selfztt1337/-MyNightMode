# QA — Settings window fix 11.1

## Root cause
The Settings scene forced `SettingsView` into a fixed 430×340 frame while the view itself required at least 620×600. SwiftUI rendered the larger content inside the smaller host window, causing severe clipping.

## Fix
- Removed the conflicting fixed frame from `NoxWindowApp.swift`.
- Added a 720×680 default Settings window size.
- Rebuilt Settings as a scrollable responsive layout.
- Replaced the overflowing horizontal preset row with a 2-column adaptive grid.
- Added fixed-size wrapping for explanatory copy.
- Updated Smart Pause copy to include 120 minutes and “until tomorrow 09:00”.

## macOS acceptance checks
- [ ] Settings opens at a readable size.
- [ ] No content is clipped at the left or right edge.
- [ ] Window can be resized down without losing access to sections.
- [ ] All sections are reachable by scrolling.
- [ ] Preset buttons fit in two columns.
- [ ] Timer picker and toggles remain aligned.
- [ ] Settings persist after restart.
