# NightMode 1.1.1 — Release Summary

## Что сделано

- Подготовлен hotfix 1.1.1 с восстановленной прозрачной иконкой приложения.
- Сохранены изменения 1.1.0: профили дисплеев, расписание, AI Auto и пользовательские пресеты.
- Добавлены согласованные светлая и тёмная иконки в стандартной macOS safe-area.
- Интерфейс проверен в светлой и тёмной темах; размеры главного окна и настроек стабилизированы.
- Menu bar, главное окно и настройки используют общие профили дисплеев и пресеты.
- README сокращён до продуктовой страницы; инженерная документация разделена на BUILD, TESTING, ARCHITECTURE и PRIVACY.
- Импорт пресетов ограничен 1 МБ до чтения; диагностический экспорт обезличен.
- Удалены 10 неиспользуемых marketing-изображений, старая заметка записи демо и локальные build/editor-артефакты.
- Расширен `.gitignore`; проведён аудит секретов, локальных путей, entitlements и зависимостей release-бинарника.

## Что ускорено и исправлено

- Неизменившийся render-state создаёт 1 Core Animation submission вместо 1 000 000 повторных отправок в benchmark.
- Paper Mode texture создаётся один раз на процесс.
- Release-приложение занимает 3,3 МБ; после запуска idle CPU — 0,0%, RSS — около 141 МБ.
- Исправлены live-preview, AI-lock ручных параметров, прокрутка пресетов, menu bar, внешние дисплеи и восстановление конфигурации.
- Приложение корректно остаётся в одном экземпляре при повторном запуске.

## Проверить перед публикацией

1. Визуальный размер новой иконки рядом с другими приложениями в Dock.
2. Полное покрытие реального внешнего монитора после sleep/wake и смены разрешения.
3. Глобальный хоткей, Smart Pause и возврат к расписанию.
4. Светлую и тёмную темы, onboarding свайпом и создание/редактирование пяти пресетов.
5. Финальные тексты README и release notes.

Commit, push и GitHub Release выполнены для 1.1.0; 1.1.1 готовится как исправление иконки.
