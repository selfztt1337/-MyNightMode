# MyNightMode V5 — Window Sync & Adaptive Eye Comfort

## Исправлено

- Исправлено глобальное преобразование координат Quartz → AppKit. Ранее overlay мог смещаться и закрывать только часть Miro.
- Частота отслеживания повышена до 30 Гц.
- Добавлена немедленная реакция на смену Space, активного приложения и конфигурации экранов.
- Overlay теперь использует `moveToActiveSpace` вместо `canJoinAllSpaces`, чтобы не оставаться на неправильном рабочем столе.
- Усилены все уровни затемнения. Night Glass при 100% теперь заметно темнее.
- Добавлен режим `AI Eye Comfort`: адаптивная интенсивность по времени суток и пользовательской чувствительности.
- Режим не использует камеру. Публичного API датчика окружающего освещения у macOS для сторонних приложений нет.
- Click-through сохранён: overlay не принимает мышь, не становится key/main window и не мешает Miro.

## QA, выполненный в текущей среде

- Проверена структура Swift Package.
- Проверены ссылки между enum, SettingsStore, OverlayController и SwiftUI views.
- Проверены shell-скрипты через `bash -n`/`zsh -n`.
- Проверен Info.plist через `plutil` при наличии инструмента.

## Что требует проверки на реальном Mac

- Фактическое совпадение overlay с Miro на конкретной конфигурации мониторов.
- Mission Control, полноэкранный режим и несколько Spaces.
- Поведение при изменении масштаба дисплея.
- Субъективная комфортность уровней затемнения.
