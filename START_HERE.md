# MyNightMode 4.0 — начать здесь

## 1. Собрать приложение

Открой Terminal в папке проекта и выполни:

```bash
chmod +x scripts/*.sh
./scripts/build_app.sh
```

Готовое приложение появится здесь:

```text
dist/MyNightMode.app
```

## 2. Первый запуск

1. Откроется короткий onboarding.
2. Нажми «Дальше» два раза и затем «Начать».
3. Оставь режим **AI**.
4. Подбери только один параметр — «Сила эффекта».
5. Дальше приложение само меняет профиль по активному приложению и контексту.

## 3. Быстро включить или выключить

```text
⌥⌘D
```

Также управление доступно из строки меню macOS.

## 4. Если сборка не прошла

```bash
./scripts/diagnose.sh
```

Пришли полный вывод ошибки в чат или Codex внутри VS Code.

> Архив подготовлен вне macOS. Реальная компиляция AppKit/SwiftUI должна быть проверена на твоём Mac командой `./scripts/build_app.sh`.
